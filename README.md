# Do Landslides Impact City Size? Evidence from Brazil - Replication Package

**Authors:** Ricardo C. A. Lima, Pedro Jorge Alves, Bruno Barsanetti, and Francisco Cavalcanti

## Overview

You can download the datasets of the replication package **[here](https://www.dropbox.com/scl/fo/5urmqltc3bvohn5qtwkbl/AKb4FIZIJ8iTR9KZlEx94t8?rlkey=1w1f79ksry5852665lvserdv0&st=3krxjljh&dl=0)** (about 16 MB). The scripts are in the `analysis/code` folder of this repository.

The analysis folder is subdivided into:

* **code**: Contains all R scripts used to generate the figures and tables.
* **output**: Stores the results generated by the scripts (JPG, PNG, TeX, and CSV files).

In the `build/output` folder of the replication package, the following datasets are available for reproducing the results (all in R format):

* `database_panel.rds`: Annual panel of 5,423 Brazilian municipalities, 2003–2020. It contains the annual outcomes and the treatment variables used in the event-study estimates.
* `database_two_periods.rds`: Municipality-level data for 2000 and 2010. It contains the covariates used in the propensity score matching (PSM), as well as the variables used in Tables 1 and 2 and in several robustness checks.
* `database_three_periods.rds`: Municipality-level data for 2000, 2010, and 2022, used for the population and household outcomes (Figure 3) and for the per capita variables in Figures 6 and E.2.

The matched sample is not distributed as a separate file: each script that uses it performs the matching from `database_two_periods.rds`.

## How to Replicate the Results

To replicate the results, please follow these steps:

1. Download and extract the replication package:
   [Replication Package](https://www.dropbox.com/scl/fo/5urmqltc3bvohn5qtwkbl/AKb4FIZIJ8iTR9KZlEx94t8?rlkey=1w1f79ksry5852665lvserdv0&st=3krxjljh&dl=0)

2. Open the main R script that sources all analysis files: `analysis/code/Master_Analysis.R`.

3. Set the following paths inside the script:

```r
DROPBOX_PATH <- "INSERT YOUR DIRECTORY PATH HERE/Landslides-Urban-Patterns"
GITHUB_PATH  <- "INSERT YOUR DIRECTORY PATH HERE/Landslides-Urban-Patterns"
```

`DROPBOX_PATH` should point to the folder where the replication package (datasets) was extracted, and `GITHUB_PATH` to the folder of this repository.

4. Set the working directory to `GITHUB_PATH`.

5. Run the script. All figures and tables will be automatically saved in:

```
./analysis/output
```
